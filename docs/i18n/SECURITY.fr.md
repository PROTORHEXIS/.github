# Politique de sécurité de PROTORHEXIS

[简体中文 / English](../../SECURITY.md) · **Français** · [Español](SECURITY.es.md) · [Русский](SECURITY.ru.md)

PROTORHEXIS prend au sérieux les vulnérabilités et la divulgation responsable. Ce texte est une **politique générale par défaut** ; les versions prises en charge, les engagements de maintenance et les procédures propres à un produit sont définis dans son dépôt.

## Champ d'application

- Ne présumez pas que tous les projets sont publiés, maintenus en production ou couverts par un programme de récompense pour la découverte de vulnérabilités.
- Consultez d'abord le `SECURITY.md` du dépôt concerné, ses versions prises en charge et ses moyens de signalement confidentiel. Sa politique spécifique prévaut.
- Aucune garantie générale de délai de réponse, de correction, de récompense ou de date de divulgation n'est donnée.

## Signaler une vulnérabilité de manière confidentielle

1. Utilisez en priorité l'option **Report a vulnerability** sur la page Security du dépôt concerné, **uniquement si elle y est effectivement activée**.
2. Si aucun canal confidentiel vérifié n'est disponible, **ne publiez pas** de détails d'exploitation, d'identifiants, de données privées ou d'exemples sensibles dans les Issues, PR, Discussions ou le profil public.
3. Si les Issues sont ouvertes, vous pouvez demander un moyen de contact sécurisé dans un message **sans aucun détail sensible**. Transmettez les détails techniques seulement une fois un canal privé confirmé.
4. Limitez les informations au strict nécessaire, masquez les données personnelles et n'effectuez aucun scan ou accès non autorisé.

## Traitement des rapports

Les responsables détermineront la suite appropriée selon l'état du projet et le risque évalué. Aucun délai précis de réponse ou de correction n'est garanti. Coordonnez la divulgation avec eux pour éviter d'accroître le risque avant vérification et atténuation.
